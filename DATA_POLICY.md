# Data Policy

This repository does not redistribute:

- Third-party datasets
- YouTube videos or extracted clips
- Identity-bearing source videos
- Third-party model weights
- Proprietary media assets
- Generated outputs based on non-permitted likenesses

Public examples should use:

- Owned media
- Explicitly licensed media
- Synthetic media
- Public-domain media
- Media with written permission for benchmark use

Benchmark input manifests should record provenance, permission basis, allowed use, and publication constraints. Local-only inputs and outputs should remain outside version control unless they are explicitly permitted for public release.
