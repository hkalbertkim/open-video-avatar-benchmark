# Adapters

Adapters describe how each candidate model would be installed, configured, smoke-tested, and benchmarked. Initial adapters are safe placeholders. They do not clone repositories, download weights, or run heavy inference.

Each adapter should record:

- Candidate identity and source repository
- Environment notes
- Installation plan
- Weight acquisition requirements
- Smoke-test command plan
- Standard benchmark input mapping
- Expected output files
- Known risks and caveats
