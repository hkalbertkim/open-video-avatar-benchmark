# Ethics

This repository is for reproducible research, benchmark methodology, and landscape analysis of publicly available video avatar systems.

The project prohibits:

- Unauthorized identity cloning.
- Publication of outputs using non-permitted likenesses.
- Benchmark media that violates privacy, consent, publicity rights, or platform terms.
- Redistribution of research media when permission covers only local evaluation.
- Mixing research metadata with redistributed source assets.

Research records may include metadata, commands, observations, failure labels, metrics, and report text. They must not include third-party datasets, private videos, extracted clips, identity-bearing source media, or restricted generated outputs unless explicit permission allows publication.

If a public artifact is disputed, open a review request with the artifact path, reason for dispute, and requested action. Maintainers should remove or quarantine disputed artifacts while reviewing permission, provenance, and publication rights.
