# Contributing

Open Video Avatar Benchmark welcomes contributions that improve reproducibility, candidate metadata, adapter coverage, evaluation protocol, and failure reporting.

Contributions should:

- Use owned, explicitly licensed, synthetic, public-domain, or otherwise permitted media.
- Avoid adding third-party datasets, model weights, checkpoints, identity-bearing videos, YouTube clips, or proprietary assets.
- Preserve source links, commit hashes, environment notes, and license caveats.
- Record failed and blocked candidates with the same care as successful candidates.
- Keep claims evidence-backed and avoid ranking models without reproducible results.

Before submitting candidate updates, check `DATA_POLICY.md`, `MODEL_POLICY.md`, and `ETHICS.md`.
